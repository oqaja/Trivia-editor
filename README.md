# Trivia Editor

Editor slide carousel Shoe Police (template Liputan Cover, Liputan Isi, dan Kotak Kuning). Semua jalan di browser: ganti foto, atur teks, warna, ketebalan per kata, gradasi, urutan slide, lalu download PNG atau ZIP 10 slide.

Buka `index.html` atau versi GitHub Pages-nya. Hasil editan tersimpan di browser masing-masing.
